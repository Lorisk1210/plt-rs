# classes derive from pybind11_object; pltrs's are Python classes.

# matplotlib draws what a program puts in a figure's artists, lines, patches
# and texts lists (Figure.get_children reads them at each draw); pltrs
# (Rust) keeps the figure's artists, so these lists are a list subclass
# whose mutating methods hand the artists over (isinstance(fig.lines, list)
# holds, and they compare equal to matplotlib's lists).
artists/(sub)?figure_(getters|setters)$ | ^type\[(artists|lines|patches|texts)\]: list -> matplotlib\._figure_artists\.DrawnList$ | the figure's lists of loose artists are a list subclass that has pltrs (Rust) draw what is put in them
