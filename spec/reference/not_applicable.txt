#
# One `test_file.py::test_name: reason` per line, grouped by test file.
# `cargo xtask mpl-tests` counts every other test as ported when the spec
# (spec/reference, crates/pltrs-spec/src) names it; `--strict` fails when a
# test is neither ported nor listed here, or when a line names a test that
# no longer exists or that the spec ports.
